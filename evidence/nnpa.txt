# LinuxONE NNPA visibility and usage check

Captured from the l1cc Ubuntu 24.04.5 s390x VM and the live `spellbreaker` container. This verifies that the platform exposes the NNPA facility; it does not show that SpellBreaker called it.

Command executed over SSH:

```sh
printf 'Host architecture: '; uname -m
printf 'Host NNPA feature line: '; grep -m1 '^features[[:space:]]*:' /proc/cpuinfo
printf 'Host grep -c nnpa: '; grep -c nnpa /proc/cpuinfo
printf 'Live service container NNPA feature line: '; docker exec spellbreaker sh -c "grep -m1 '^features[[:space:]]*:' /proc/cpuinfo"
printf 'Live service container grep -c nnpa: '; docker exec spellbreaker sh -c 'grep -c nnpa /proc/cpuinfo'
printf 'zDLC executable: '; command -v zdlc || echo not-installed
printf 'zDLC/ONNX Runtime packages: '; dpkg-query -W -f='${binary:Package} ${Version}\\n' 2>/dev/null | grep -Ei 'zdlc|onnxruntime' || echo none-found
```

Output:

```text
Host architecture: s390x
Host NNPA feature line: features	: esan3 zarch stfle msa ldisp eimm dfp edat etf3eh highgprs te vx vxd vxe gs vxe2 vxp sort dflt vxp2 nnpa sie 
Host grep -c nnpa: 1
Live service container NNPA feature line: features	: esan3 zarch stfle msa ldisp eimm dfp edat etf3eh highgprs te vx vxd vxe gs vxe2 vxp sort dflt vxp2 nnpa sie 
Live service container grep -c nnpa: 1
zDLC executable: not-installed
zDLC/ONNX Runtime packages: none-found
```

Interpretation: `nnpa` is present in `/proc/cpuinfo` on both host and service container (`grep -c` = 1). The check did not find a `zdlc` executable or zDLC/ONNX Runtime package. A code search of `service/`, `ml/`, `service/Containerfile`, `service/requirements.txt` and `ml/requirements.txt` found no `zdlc`, `nnpa` or `onnxruntime` integration. Therefore the evidence supports **NNPA available on the LinuxONE environment**, not **SpellBreaker inference accelerated by NNPA**. Do not claim the latter without compiling/loading a supported model and capturing a successful inference run.
